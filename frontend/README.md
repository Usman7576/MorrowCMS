# Frontend Prototype

This folder contains the Activity 1 browser prototype for the Cafe Management System.

- `index.html`: landing page
- `login.html`: demo waiter login
- `dashboard.html`: waiter order workspace
- `styles.css`: shared responsive styles
- `app.js`: validation, session guard, menu interactions, order state, and feedback

The frontend currently uses local demo data. It should later call the API in `../backend/` instead of owning authentication, menu, order, or inventory data.
